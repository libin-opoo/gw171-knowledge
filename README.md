# 金风风机3D知识库 · 在线版

这是「金风风机3D知识库」的**只读在线版**，直接从浏览器打开，不用安装。

## 能做什么

- 看整机三维模型，点部件直达资料
- 查部件目录（82 个部件）
- 查**出厂参考**卡片（液压、电气参数等）
- 翻两本培训教材（整本扫描页，可放大、可全文检索并高亮命中位置）

## 不能做什么（这是静态托管的天然限制，不是坏了）

- ❌ 新增 / 修改 / 删除自己的资料
- ❌ 记维修记录
- ❌ 手机与电脑同步
- ❌ 导出备份

要这些功能，请用**电脑版**或**手机版 App**（数据存在自己设备上，离线可用）。

## 为什么分成两个版本

数据分两类：

| 类型 | 例子 | 放哪 |
|---|---|---|
| **死的**（谁看都一样） | 部件目录、出厂参考、教材、三维模型 | 可以放静态托管 ✅ |
| **活的**（要能写） | 你自己录的资料、维修记录、同步 | 必须有程序，只能放本机 |

静态托管跑不了程序，所以只能承载「死」的那一半。

## 技术说明

原版网页靠本机 Python 程序提供 `/api/*` 接口。这个在线版在构建时
从真实服务抓了一份接口响应的**快照**，再用 `static-mode.js` 把请求改接过去。
因此接口形状与原版完全一致——快照是抓来的，不是手写的。

写操作会被明确拒绝并提示原因（不会静默失败让你以为存上了）。
